# React + Vite

## Project Name: What To Wear

### Description:

This project is built to help determine what type of clothes one should wear based on the current weather conditions in a set location. The project uses an APIkey to see the weather in an area, assign a category for that weather, & then filter possible clothing options based on that weather.

#### Technologies Used:

OpenWeatherAPI, Dot (AI), React
